# Test media

Tiny sample files used by `make test` to exercise the decoders.

`sfx.mp3`, `sfx.flac`, `sfx.aac`, `sfx-aac.mp4`, `sfx-opus.ogg` and
`sfx-vorbis.ogg` come from the web-platform-tests project
(https://github.com/web-platform-tests/wpt, directory `webcodecs/`; `sfx.aac`
is its `sfx.adts` renamed) and are used under its 3-clause BSD licence,
reproduced in `LICENSE.md`. Each is a fraction of a second of a sound effect.

WAV files and a tracker module are generated by the tests themselves.
